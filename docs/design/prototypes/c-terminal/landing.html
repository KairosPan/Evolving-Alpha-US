NAME

kairos — a single trading-research agent, run by a single operator, on DeepSeek Harness. It works a three-layer workbench; its authority over its own runtime is zero.

SYNOPSIS

kairos marketpoint-in-time US equities · Alpaca + EDGAR · lookahead-guarded kairos strategythe arena · git-versioned theses, screens, backtests, journals kairos accountAlpaca paper · read-only · orders double-gated, both closed

DESCRIPTION

MARKET and ACCOUNT are one Python package with two faces — importable library for backtests, MCP server for interactive queries — sharing the same point-in-time guards. STRATEGY is the agent's arena: a strategy is a git-versioned directory holding a thesis with falsification conditions, an executable screen, backtests, a journal, and a lifecycle state.

The operator teaches directly — an operator-owned style pack, conversation, and review. The runtime, the credentials, and every gate flag live outside the agent's reach. Enforced by placement, not by rules.

PRINCIPLES

P1WIDE HANDS, NO SELF-KEYS
The action space is large: shell, code, market tools, the whole arena. Authority over its own runtime: zero. The profile, keys, and gate flags live in the harness home, outside the workspace.
P2THE OPERATOR IS THE ONLY TEACHER
Style is operator-owned. When research conflicts with a style entry, Kairos reports the conflict — never silently defers, never silently overrides.
P3POINT-IN-TIME HONESTY, IN CODE
Every dated market read passes a lookahead guard; guard surfaces are pinned by name in tests. A backtest that cannot be honest fails loudly, never succeeds approximately.
P4HONEST EVALUATION
Five backtest rules bind every experiment: PIT channel only · a delisting during a hold is a terminal loss · returns are gross and say so · no same-day round trip · missing data is discarded and counted, never fabricated.
P5THE HUMAN IS THE STEADY STATE
No autonomy ladder, no graduation criteria. Operator attention is the binding rate limit — economized, never designed away.
